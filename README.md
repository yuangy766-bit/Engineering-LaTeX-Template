# Engineering LaTeX Toolkit for Engineers/XMUMers

A reusable collection of LaTeX templates, academic resources, and practical document formats developed throughout my undergraduate studies in Electrical and Electronic Engineering at Xiamen University Malaysia.

This repository is not intended to be a single LaTeX template. Instead, it serves as a growing academic toolkit containing the templates, formatting structures, and reusable components that I have gradually organized and refined through coursework, laboratory reports, projects, technical papers, and other academic activities.

The main goal of this repository is simple:

> To save students from repeatedly rebuilding the same academic documents from scratch.

Although some templates are specifically designed for Xiamen University Malaysia students, most of the LaTeX structures and examples can also be adapted for students from other universities.

---

## About This Repository

Throughout my undergraduate studies, I found myself repeatedly working with similar document structures:

- Assignment cover pages
- Engineering reports
- Laboratory reports
- Project reports
- IEEE-style papers
- Tables and figures
- Mathematical equations
- References and citations
- Resume formats
- Technical documentation

Instead of recreating these components every semester, I gradually built a personal collection of LaTeX templates and reusable code.

This repository is an attempt to organize and open-source those materials so that other students, especially XMUM students, can use, modify, and improve them.

The templates included here are primarily based on documents that I have actually used during my studies rather than purely theoretical examples.
